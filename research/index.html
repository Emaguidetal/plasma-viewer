Original LXCat cross-section downloads are not redistributed because their headers state “All rights reserved.” The reported results are numerical modeling, not validated experimental predictions; see the reports for assumptions and limitations.

Scope of this upload

This package includes reports, source, inputs, tests, scan tables, and figures. It does not include 3.23 GB of intermediate time-resolved binary field archives, the local Python virtual environment, or bundled solver binaries; those are large, machine-specific run artifacts rather than the curated results package. The saved metrics and plotted summaries for the reported scans are included.
